# anumod-neeraja

Wedding invitation for Anumod & Neeraja — Friday, 13 November 2026.

A static page (`index.html`, `style.css`, `script.js`) with no build step; open `index.html` or serve the folder.

- `assets/` holds the web-sized images and the link-preview image (`og.jpg`).
- `photos/` is the local source folder. Originals stay on this computer — `.gitignore` keeps them off GitHub — and the site uses the resized copies in `assets/`.
- `?open` or a section link (`#ceremonies`) skips the envelope opening.
